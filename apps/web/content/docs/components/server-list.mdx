## Installation

```npm
npx shadcn@latest add @runqora/craft-server-list
```

## Usage

```tsx
import {
  ServerList,
  ServerListItem,
  ServerListLabel,
} from "@/components/craft/server-list";

<ServerList aria-label="Servers">
  <ServerListLabel>Featured</ServerListLabel>
  <ServerListItem
    name="Gemfall"
    onJoin={() => join("gemfall")}
    ping={38}
    players={{ max: 20000, online: 12737 }}
  />
</ServerList>;
```

## Accessibility

- Each Join button is named after its server, such as "Join Gemfall", so they can be told apart. It's disabled while connecting and while offline.
- The ping bars are also said in words, such as "Excellent ping, 38 ms". Player counts are read as "12,737 of 20,000 players".
- The favorite star is a toggle button, with its state announced as pressed or not. Its outline fills in when on, so it doesn't rely on color.
- A connecting server is announced with a status message.

## Customization

The list has no networking of its own: pass it what your backend reports, and handle `onJoin` and `onFavoriteChange`.

`ServerPing` and `ServerPlayers` can be used on their own, such as on a server's detail page. Four bars are up to 80 ms, three up to 150 ms, two up to 300 ms, and one above that. Their colors are `--craft-signal-good`, `--craft-signal-fair` and `--craft-signal-poor`.
