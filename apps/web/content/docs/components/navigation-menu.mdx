## Installation

```npm
npx shadcn@latest add @runqora/craft-navigation-menu
```

## Usage

```tsx
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuList,
  NavigationMenuTrigger,
} from "@/components/craft/navigation-menu";

<NavigationMenu aria-label="Main">
  <NavigationMenuList>
    <NavigationMenuItem>
      <NavigationMenuLink active href="/play">
        Play
      </NavigationMenuLink>
    </NavigationMenuItem>
    <NavigationMenuItem>
      <NavigationMenuTrigger>Marketplace</NavigationMenuTrigger>
      <NavigationMenuContent>
        <NavigationMenuLink href="/marketplace/worlds">Worlds</NavigationMenuLink>
      </NavigationMenuContent>
    </NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>;
```

## Accessibility

- It's a `nav` landmark. When a page has more than one, name each with `aria-label`.
- The current page's link has `aria-current="page"`, as well as its underline or lifted row.
- Tab moves between the items. Enter, Space or the arrow keys open a panel, and Escape closes it.
- Panels open on hover too, after a short delay, and stay open while the pointer moves into them.

## Customization

For client-side routing, pass your framework's link through `render`:

```tsx
import NextLink from "next/link";

<NavigationMenuLink active render={<NextLink href="/settings" />}>
  Settings
</NavigationMenuLink>;
```
