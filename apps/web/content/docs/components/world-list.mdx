## Installation

```npm
npx shadcn@latest add @runqora/craft-world-list
```

## Usage

```tsx
import { WorldCard, WorldList } from "@/components/craft/world-list";

<WorldList aria-label="Worlds">
  {worlds.map((world) => (
    <WorldCard
      key={world.id}
      meta="Last played yesterday"
      name={world.name}
      onDelete={() => remove(world.id)}
      onEdit={() => edit(world.id)}
      onPlay={() => play(world.id)}
      tags={<Badge>Survival</Badge>}
      thumbnail={<img alt="" src={world.picture} />}
    />
  ))}
</WorldList>;
```

## Accessibility

- The whole card opens the world, through one button named "Play" and the world's name. Its focus ring outlines the card.
- Edit and Delete are named with the world too, such as "Edit Riverside".
- Delete opens an alert dialog that names the world. Focus starts inside it, and Cancel or Escape close it without deleting.
- Pictures are decorative, because the name is beside them: give an `<img>` an empty `alt`.

## Customization

Search, sorting and creating are left to your app, as in the example above: filter and sort the worlds, then render the cards. The list lays the cards out in as many columns as fit.

Without a `thumbnail`, a card shows a plain landscape. Pass `onPlay`, `onEdit` and `onDelete` only for what a player can do: a card leaves out the buttons it has no handler for.

The labels are props, so they can be translated.
