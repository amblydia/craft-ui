## Installation

```npm
npx shadcn@latest add @runqora/craft-button
```

This writes `components/craft/button.tsx` and `button-variants.ts`, and adds the
[CraftUI theme](/docs/themes) to your CSS. See [Installation](/docs/installation)
if you haven't added the registry yet.

## Usage

```tsx
import { Button } from "@/components/craft/button";

<Button>Play</Button>;
```

### Disabled and loading

A disabled button turns gray and can't be focused. A loading button keeps its
color and its keyboard focus, shows a spinner, and ignores clicks until it's
done, so someone using a keyboard doesn't lose their place.

## Accessibility

- Renders a native `<button>` with `type="button"`, so it won't submit a form
  unless you ask it to with `type="submit"`.
- Works with Enter and Space, and shows a solid focus ring for keyboard users.
- `loading` sets `aria-busy` and keeps the button focusable.
- The hover color is brighter than in the game, so hovered primary and
  destructive buttons use a dark label to keep a contrast of at least 4.5:1.

## Customization

Every color comes from a token, so you can change one button without touching
the component.

To match the white hover label in the game, set
`--craft-primary-hover-fg: #ffffff`. It falls below AA contrast, so it's not the
default. For a change everywhere, edit the tokens in your CSS. See
[Themes](/docs/themes).
