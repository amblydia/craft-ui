## Accessibility

- Has the `switch` role, and Space toggles it.
- `label` is joined to the switch, so clicking the text works too. Without a
  label, pass `aria-label`.
- The I and O marks show the state as well as the color.

## Customization

The size of the switch follows `--craft-unit`, so a larger unit makes a larger
switch with the same proportions.

```tsx
<Switch className="[--craft-unit:3px]" label="Big switch" />
```
