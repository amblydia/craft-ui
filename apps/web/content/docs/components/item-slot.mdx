## Installation

```npm
npx shadcn@latest add @runqora/craft-item-slot
```

## Usage

```tsx
import { ItemSlot, ItemTooltip } from "@/components/craft/item-slot";

const torch = { count: 24, icon: <img alt="" src="/torch.png" />, id: "torch", name: "Torch" };

<ItemSlot item={torch} />;

// One that can be pressed, with a tooltip.
<ItemTooltip item={torch}>
  <ItemSlot item={torch} render={<button type="button" />} />
</ItemTooltip>;
```

## Accessibility

- A slot holds its label as hidden text, such as "Iron Pickaxe, 40% durability", so it's read wherever it's used. The icon is hidden from screen readers.
- Use `itemLabel(item)` to build the same text yourself, and the `label` prop to replace it, for example to translate it.
- A slot on its own is a `div`. For one that can be pressed, render it as a button: it's then named by its label.
- Selected and disabled slots differ in more than color: a selected slot gets a thick frame, and a disabled one is hatched.
- Base UI tooltips aren't read by screen readers, so put anything a player needs in the label, not only in `description`.

## Customization

Items are plain objects from your app. CraftUI never looks them up:

```ts
interface Item {
  id: string; // a stable id, for React keys
  name: string; // read out as the slot's label, and the tooltip's title
  icon?: ReactNode; // usually an <img>, or an SVG
  count?: number; // shown from 2
  durability?: number; // 0 to 1, shown as a bar below 1
  description?: ReactNode; // more lines for the tooltip
}
```

The slot's colors are `--craft-slot`, `--craft-slot-hi` and `--craft-slot-lo`. `itemSlotClassName` holds its look, for anything that should match it.

Icons are drawn with `image-rendering: pixelated`, so small pixel art stays sharp when it's scaled up.
