## Installation

```npm
npx shadcn@latest add @runqora/craft-toast
```

## Usage

```tsx
// Once, around your app, for instance in app/layout.tsx:
import { ToastProvider } from "@/components/craft/toast";

<ToastProvider>{children}</ToastProvider>;

// Anywhere inside it:
"use client";
import { useToast } from "@/components/craft/toast";

const toast = useToast();
toast.add({ title: "World saved", type: "success" });
```

## Accessibility

- Toasts are announced politely as they appear. Pass `priority: "high"` for something urgent, which interrupts.
- F6 moves focus to the toasts, where Tab reaches their buttons. While focus or the pointer is on them, they don't close by themselves.
- Each toast has a Dismiss button, and can be swiped away on a touch screen.
- Don't put the only way to do something in a toast, as it closes after five seconds.

## Customization

`type` sets the color: `success`, `error`, `warning` or `info`. Without one, a toast uses the surface color.

To add toasts from outside React, create a manager with `createToastManager()` and pass it to `ToastProvider` as `toastManager`.
