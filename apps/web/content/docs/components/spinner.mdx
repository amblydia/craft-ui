## Installation

```npm
npx shadcn@latest add @runqora/craft-spinner
```

## Usage

```tsx
import { LoadingOverlay, Spinner } from "@/components/craft/spinner";

<Spinner label="Loading worlds" />;

<LoadingOverlay loading={isLoading}>
  <WorldList />
</LoadingOverlay>;
```

## Accessibility

- Both are a status, so screen readers announce the label. The spinner's label is hidden on screen unless you set `showLabel`.
- The overlay marks its content `aria-busy` and `inert` while loading.
- With reduced motion, the spinner stays still.
- For progress you can measure, use [Progress](/docs/components/progress) instead.

## Customization

The spinner takes the text color, so set `className="text-craft-primary"` or any other color on it. The overlay's cover uses `--craft-overlay`.
