## Installation

```npm
npx shadcn@latest add @runqora/craft-progress
```

## Usage

```tsx
import { Progress } from "@/components/craft/progress";

<Progress label="Downloading pack" showValue value={40} />;
```

## Accessibility

- Has the `progressbar` role, with its current value for screen readers.
- `label` names the bar. Without one, pass `aria-label`.
- Pair a tone with a label or message, since color alone doesn't say what
  happened.

## Customization

`color` takes any CSS color, and a custom color replaces the highlights too. To
restyle a tone everywhere, edit its tokens, such as `--craft-info` and
`--craft-info-hi`.
