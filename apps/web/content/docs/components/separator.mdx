## Installation

```npm
npx shadcn@latest add @runqora/craft-separator
```

## Usage

```tsx
import { Separator } from "@/components/craft/separator";

<Separator />;
<Separator orientation="vertical" />;
```

A vertical separator takes the height of its container, so give the container
a height.

## Accessibility

- Has the `separator` role and its orientation for screen readers.
- If it's only decoration, render a plain element instead, so that it isn't
  announced.

## Customization

The groove is two lines drawn from the surface tokens, and `--craft-unit` sets
how thick they are.

```tsx
<Separator className="[--craft-unit:1px]" />
```

## Dependencies

- [`@base-ui/react`](https://base-ui.com/react/components/separator)
- shadcn's `utils`, and `craft-theme`
