## Installation

```npm
npx shadcn@latest add @runqora/craft-table
```

## Usage

```tsx
import {
  Table,
  TableBody,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from "@/components/craft/table";

<Table>
  <TableHeader>
    <TableRow>
      <TableHead>World</TableHead>
      <TableHead>Mode</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>Harbor</TableCell>
      <TableCell>Survival</TableCell>
    </TableRow>
  </TableBody>
</Table>;
```

## Accessibility

- It's a real HTML table, so screen readers can move by row and column and read each cell's heading.
- A sortable heading holds a button, and the heading's `aria-sort` says how the column is sorted.
- Selection is a [Checkbox](/docs/components/checkbox) in each row, named after the row. Selected rows have a green bar as well as their color.
- `TableLoading` is a status, so screen readers announce it.

## Customization

Wide tables scroll sideways inside their frame. The table renders on the server; sorting needs an `onSort` handler, so a sortable table lives in a client component.
