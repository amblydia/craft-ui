## Installation

```npm
npx shadcn@latest add @runqora/craft-dialog
```

## Usage

```tsx
import {
  Dialog,
  DialogBody,
  DialogContent,
  DialogDescription,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@/components/craft/dialog";

<Dialog>
  <DialogTrigger>Open</DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>World details</DialogTitle>
    </DialogHeader>
    <DialogBody>
      <DialogDescription>Created on May 15.</DialogDescription>
    </DialogBody>
  </DialogContent>
</Dialog>;
```

To use a CraftUI button as the trigger or a close action, pass it through
`render`: `<DialogTrigger render={<Button />}>Open</DialogTrigger>`.

### DialogBack

A back arrow for dialogs with several steps. It's a button, so give it an `onClick`
and place it inside `DialogContent`. Its accessible name defaults to "Back".

```tsx
<DialogContent>
  <DialogBack onClick={() => setStep(1)} />
  <DialogHeader>
    <DialogTitle>Choose a world</DialogTitle>
  </DialogHeader>
</DialogContent>
```

## Accessibility

- Always include a `DialogTitle`, which names the dialog for screen readers.
  `DialogDescription` is announced as its description.
- Focus moves into the dialog when it opens and stays there, and it returns to
  the trigger when the dialog closes.
- Escape closes the dialog, and so does clicking the backdrop.
- For a destructive choice, consider `initialFocus` to start on the safer action.

## Customization

Set the width on `DialogContent`. The dialog always fits a narrow screen, and
`DialogBody` scrolls when the content is tall.

```tsx
<DialogContent className="max-w-2xl">...</DialogContent>
```
