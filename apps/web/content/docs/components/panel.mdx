## Installation

```npm
npx shadcn@latest add @runqora/craft-panel
```

## Usage

```tsx
import {
  Panel,
  PanelContent,
  PanelHeader,
  PanelTitle,
} from "@/components/craft/panel";

<Panel>
  <PanelHeader>
    <PanelTitle>Harbor</PanelTitle>
  </PanelHeader>
  <PanelContent>A survival world.</PanelContent>
</Panel>;
```

Every part is optional, so a panel can be only `PanelContent`. It has no client
code, so it works in React Server Components with no boundary.

Each part also accepts every attribute of the element it renders: `<div>` for
most parts, `<h3>` for `PanelTitle` and `<p>` for `PanelDescription`.

## Accessibility

- `PanelTitle` renders an `<h3>`. If that doesn't fit your page's heading order,
  render your own heading inside `PanelHeader`.
- A panel has no role of its own. When it's a landmark on your page, add `role`
  and a label, or wrap it in a `<section>`.

## Customization

Panels read their padding from `--craft-space`, on any level you set it.

```tsx
<Panel className="[--craft-space:2rem]">...</Panel>
```

## Dependencies

- `class-variance-authority`
