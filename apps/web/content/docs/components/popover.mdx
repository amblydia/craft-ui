## Installation

```npm
npx shadcn@latest add @runqora/craft-popover
```

## Usage

```tsx
import {
  Popover,
  PopoverContent,
  PopoverDescription,
  PopoverTitle,
  PopoverTrigger,
} from "@/components/craft/popover";

<Popover>
  <PopoverTrigger>Seed</PopoverTrigger>
  <PopoverContent>
    <PopoverTitle>World seed</PopoverTitle>
    <PopoverDescription>Share it to make the same world.</PopoverDescription>
  </PopoverContent>
</Popover>;
```

## Accessibility

- The popover is a dialog named by `PopoverTitle` and described by `PopoverDescription`.
- Focus moves into it when it opens, Escape closes it, and focus returns to the trigger.
- Use a [Tooltip](/docs/components/tooltip) for a short hint, and a popover when there's something to do.

## Customization

The panel is 18rem wide. Change it with `className` on `PopoverContent`, which never grows past the space on screen.

## Dependencies

- [`@base-ui/react`](https://base-ui.com/react/components/popover)
- shadcn's `utils`, and `craft-theme`
