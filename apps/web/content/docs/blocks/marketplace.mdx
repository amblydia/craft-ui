In the style of Ore UI's marketplace screens.

## Installation

```npm
npx shadcn@latest add @runqora/craft-marketplace
```

## Usage

```tsx
import { Marketplace } from "@/components/craft/blocks/marketplace";

<Marketplace
  categories={[{ label: "Worlds", value: "worlds" }]}
  onSelect={(product) => openProduct(product.id)}
  products={products}
/>;
```

## Accessibility

- Each card opens through a button named after the product.
- Ratings and prices are read in words, such as "Rated 4.5 out of 5" and "1,340 coins".
- The pages are links in a navigation landmark, with the current page marked.

## Customization

The coin is a plain drawing: swap `CoinIcon` for your store's currency. The block keeps only what's on screen, such as the search text. Your data comes in through props, and every action calls one of your handlers, so it works with any backend. Every screen fills its frame, so give it a height, such as `h-dvh` for a whole page.

## Dependencies

- `craft-badge`, `craft-input`, `craft-pagination`, `craft-screen` and `craft-select`
- shadcn's `utils`, and `craft-theme`
