A block is a whole screen, such as a main menu or a server browser, built from
CraftUI's components and laid out as Ore UI's screens are. Install one, and it's
yours to change, like any shadcn/ui block.

Blocks take your data and your handlers as props, and never call a game or a
server. They keep only what's on screen, such as a search box's text.

## Install a block

Blocks install into `components/craft/blocks`, along with the components they
use:

```npm
npx shadcn@latest add @runqora/craft-server-browser
```

## Fill the window

Every block is a Screen, which fills its frame. For a whole page, give it the
window's height:

```tsx
<ServerBrowser className="h-dvh" onJoin={join} servers={servers} />
```

Screens are containers, so their layouts follow their own width, not the
window's. Each block's page has a link to see it on a page of its own.

## The blocks

| Block | What it's for |
|---|---|
| [Main Menu](/docs/blocks/main-menu) | The first screen, with Play and other choices |
| [Settings Screen](/docs/blocks/settings-screen) | Settings, built from a list |
| [Server Browser](/docs/blocks/server-browser) | Finding and joining a server |
| [World Browser](/docs/blocks/world-browser) | Picking, creating and deleting worlds |
| [Inventory Screen](/docs/blocks/inventory-screen) | A backpack and a hotbar |
| [Profile Screen](/docs/blocks/profile-screen) | A player's profile and achievements |
| [Confirmation Dialog](/docs/blocks/confirmation-dialog) | Asking before something can't be undone |
| [Game Dashboard](/docs/blocks/game-dashboard) | Watching and controlling a world |
| [Multiplayer Lobby](/docs/blocks/multiplayer-lobby) | Getting players ready before a game |
| [Marketplace](/docs/blocks/marketplace) | Browsing and buying content |

They're all built on [Screen](/docs/blocks/screen), which you can use for your own.
