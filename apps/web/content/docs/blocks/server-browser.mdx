Follows Ore UI's Servers tab: the list on one side and the chosen server on the other.

## Installation

```npm
npx shadcn@latest add @runqora/craft-server-browser
```

## Usage

```tsx
import { ServerBrowser } from "@/components/craft/blocks/server-browser";

<ServerBrowser
  onAddServer={openAddServer}
  onFavoriteChange={(server, favorite) => setFavorite(server.id, favorite)}
  onJoin={(server) => join(server.id)}
  servers={servers}
/>;
```

## Accessibility

- Each server's name is a button that shows its details, marked as the current one.
- The details are a region named after the server, and Play is named after it too, such as "Play Gemfall". It's disabled while connecting or offline.
- The search box and Favorites only switch are labelled.

## Customization

The block keeps only what's on screen, such as the search text. Your data comes in through props, and every action calls one of your handlers, so it works with any backend. On a narrow screen, the details sit under the list. Every screen fills its frame, so give it a height, such as `h-dvh` for a whole page.

## Dependencies

- `craft-button`, `craft-input`, `craft-screen`, `craft-server-list` and `craft-switch`
- shadcn's `utils`, and `craft-theme`
