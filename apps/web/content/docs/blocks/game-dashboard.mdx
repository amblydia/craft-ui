In the style of the forms Ore UI shows in game, such as a live world dashboard.

## Installation

```npm
npx shadcn@latest add @runqora/craft-game-dashboard
```

## Usage

```tsx
import {
  GameDashboard,
  GameDashboardAction,
} from "@/components/craft/blocks/game-dashboard";

<GameDashboard
  actions={<GameDashboardAction onClick={restart}>Restart</GameDashboardAction>}
  hour={hour}
  onHourChange={setHour}
  onWeatherChange={setWeather}
  status="online"
  weather={weather}
  worldName="Riverside"
/>;
```

## Accessibility

- The numbers are terms and values, the bars are progress bars named by their labels, and the events are a table.
- The status is a tag with words, such as Online, not only a color.

## Customization

The block keeps only what's on screen, such as the search text. Your data comes in through props, and every action calls one of your handlers, so it works with any backend. Every screen fills its frame, so give it a height, such as `h-dvh` for a whole page.

## Dependencies

- `craft-badge`, `craft-button`, `craft-panel`, `craft-progress`, `craft-screen`, `craft-select`, `craft-slider` and `craft-table`
- shadcn's `utils`, and `craft-theme`
