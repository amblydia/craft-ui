## Installation

```npm
npx shadcn@latest add @runqora/craft-inventory-screen
```

## Usage

```tsx
import { InventoryScreen } from "@/components/craft/blocks/inventory-screen";

<InventoryScreen
  defaultContents={{ hotbar, inventory }}
  onContentsChange={save}
  onDrop={(item) => drop(item.id)}
  onUse={(item) => use(item.id)}
/>;
```

## Accessibility

- The backpack is a grid and the hotbar a list, both named, with the keyboard support of Inventory Grid and Hotbar.
- The details say the chosen item's name, description and durability in words.
- Move to hotbar and Move to backpack let keyboard players move items between the two, which dragging alone wouldn't.

## Customization

The screen keeps the slots once it starts, and reports every change through `onContentsChange`, so you can save them. Items are the same objects as in Item Slot. Every screen fills its frame, so give it a height, such as `h-dvh` for a whole page.

## Dependencies

- `craft-button`, `craft-hotbar`, `craft-inventory-grid`, `craft-item-slot`, `craft-progress` and `craft-screen`
- shadcn's `utils`, and `craft-theme`
