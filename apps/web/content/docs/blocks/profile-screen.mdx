## Installation

```npm
npx shadcn@latest add @runqora/craft-profile-screen
```

## Usage

```tsx
import { ProfileScreen } from "@/components/craft/blocks/profile-screen";

<ProfileScreen
  completed={completed}
  profile={{ name: "Skylark", status: "online" }}
  stats={[{ label: "Friends", value: "3" }]}
  suggested={suggested}
/>;
```

## Accessibility

- The player's name is a heading, and Overview and Stats are tabs.
- Achievement points are read as points, such as "20 points".
- The status is said in words as well as by color.

## Customization

Suggested achievements sit under a blue heading and completed ones under a green one, as in Ore UI. Every screen fills its frame, so give it a height, such as `h-dvh` for a whole page.

## Dependencies

- `craft-profile-panel`, `craft-screen` and `craft-tabs`
- shadcn's `utils`, and `craft-theme`
