Installing any component adds the CraftUI theme to your CSS. It's made of CSS
variables that all start with `--craft-`, so it sits beside your existing theme,
including shadcn/ui's, and changes nothing in it.

## One design

Ore UI is one design, so CraftUI has no light or dark mode. Every value is on
`:root`, and the components look the same whatever color scheme the rest of your
app uses, including a `dark` class. Put them on `bg-craft-background`, or another
CraftUI surface, so that their text stays readable.

If you installed CraftUI before this change, your CSS may still have `--craft-`
variables under `.dark`. Delete them, and the components follow the one design.

## Change a token

Edit the values in your CSS file, which is the one that `shadcn add` wrote to.

```css
:root {
  --craft-primary: #2e6be5;
  --craft-primary-hi: #5889ea;
  --craft-primary-lo: #4a7fe8;
  --craft-primary-edge: #16356f;
}
```

Tokens also work on any element, for that element and everything inside it.

```tsx
<div className="[--craft-unit:3px] [--craft-radius:4px]">
  <Button>Bigger bevels, rounded corners</Button>
</div>
```

## All the tokens

| What | Tokens |
|---|---|
| **Geometry** | `--craft-unit` (borders and bevels), `--craft-edge` (the thick base), `--craft-radius` |
| **Spacing** | `--craft-space`, `--craft-control-sm`, `--craft-control-md`, `--craft-control-lg` |
| **Type** | `--craft-font-display`, `--craft-font-body`, `--craft-label-size` |
| **Fonts** | `--craft-font-display` (labels and titles), `--craft-font-body` (long text) |
| **Focus** | `--craft-focus`, `--craft-focus-width` |
| **Text** | `--craft-text`, `--craft-text-muted`, `--craft-placeholder` |
| **Surfaces** | `--craft-background`, `--craft-surface`, `--craft-raised`, `--craft-sunken`, `--craft-field`, `--craft-outline`, each with `-hi`, `-lo` or `-edge` shades where they apply |
| **Actions** | `--craft-primary`, `--craft-secondary`, `--craft-destructive`, each with `-hi`, `-lo`, `-edge` and `-fg`, plus `-hover` and `-active` sets |
| **Disabled** | `--craft-disabled`, `--craft-disabled-edge`, `--craft-disabled-outline`, `--craft-disabled-fg` |
| **Tracks and status** | `--craft-track`, `--craft-info`, `--craft-warning`, each with `-hi` and `-lo` |
| **Overlays** | `--craft-tooltip`, `--craft-tooltip-fg`, `--craft-overlay` |

The tokens also become Tailwind utilities, such as `bg-craft-surface`,
`text-craft-text-muted` and `font-craft-display`, for your own layouts.

## Fonts

Labels use [Departure Mono](https://departuremono.com/) by Helena Zhang, under the
SIL Open Font License. **The theme installs it for you**, as the
`@runqora/departure-mono` package, so there's nothing to set up. Your bundler serves
the font from your own app, like any other asset.

It's drawn on an 11-pixel grid, so it's sharpest at multiples of 11px. Controls use
`--craft-label-size`, which is 22px. Departure Mono has one weight, and browsers
smear its pixels when they fake a bold, so set `font-synthesis: none` on any heading
you bold, or on your `body`.

Long text uses [Noto Sans](https://fonts.google.com/noto/specimen/Noto+Sans), also
under the SIL Open Font License, and falls back to your system's sans-serif font. The
theme doesn't load this one, so your app doesn't pay for a font it may not want. To
load it in Next.js:

```tsx title="app/layout.tsx"
import { Noto_Sans } from "next/font/google";

const body = Noto_Sans({ subsets: ["latin"], variable: "--font-noto-sans" });

export default function RootLayout({ children }) {
  return (
    <html className={body.variable} lang="en">
      <body>{children}</body>
    </html>
  );
}
```

In other React apps, install it with Fontsource and import it.

```npm
npm install @fontsource-variable/noto-sans
```

```ts title="src/main.tsx"
import "@fontsource-variable/noto-sans";
```

```css
:root {
  --font-noto-sans: "Noto Sans Variable";
}
```

To use different fonts, set `--craft-font-display` and `--craft-font-body`.

## Contrast

The default tokens meet WCAG AA, 4.5:1 for text and 3:1 for the focus ring, with
one exception taken from the game: hovered buttons keep their white label, at
3.1:1 on green and 2.4:1 on red. Keep contrast in mind when you choose your own
colors. If you change a fill, change its `-fg` token to match.
