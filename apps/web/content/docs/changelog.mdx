CraftUI is installed as source, so a release never changes your code by itself.
To pick up a change, run `npx shadcn@latest add @runqora/craft-button --diff` to
review it, then apply what you want.

## Unreleased

The first set of components, not yet announced.

- **Components:** Button, Input, Checkbox, Switch, Slider, Progress, Tabs, Panel,
  Dialog, Tooltip, Separator and Scroll Area
- **Theme:** the `craft-theme` tokens for light and dark, measured from published
  Ore UI references
- **Registry:** valid shadcn registry items at `/r/{name}.json` and
  `/r/{style}/{name}.json`
- **Docs:** this site, with live previews and interactive examples
